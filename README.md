# DEVCONF 2026 - лендинг IT-конференции на React и React Bootstrap

Лабораторная работа № 23. Стилизация React-приложения с использованием
компонентов библиотеки Bootstrap.

Вариант 2: лендинг IT-конференции. Проект продолжает работы № 19 и № 22:
структура страницы, данные и хранилище Redux перенесены оттуда, а вся
вёрстка переписана на готовые компоненты React Bootstrap.

## Стек

- React 18, функциональные компоненты и хуки
- React Bootstrap 2 и Bootstrap 5.3 - UI-библиотека и её таблица стилей
- Redux Toolkit 2 и React-Redux 9 - глобальное состояние избранного
- Vite 5 как сборщик и dev-сервер
- PropTypes для описания контрактов компонентов

## Требования

- Node.js версии 18 или новее
- npm версии 9 или новее

## Запуск

```bash
git clone <адрес репозитория>
cd devconf-react-bootstrap
npm install
npm run dev
```

Vite выведет в терминал адрес локального сервера, по умолчанию
http://localhost:5173.

Если проект разворачивается поверх копии ЛР № 22, недостающие пакеты
ставятся командой:

```bash
npm install react-bootstrap bootstrap
```

## Остальные команды

```bash
npm run build     # production-сборка в каталог dist
npm run preview   # локальный просмотр собранной версии
```

## Подключение библиотеки

Стили и компоненты подключаются раздельно. Таблица стилей импортируется
один раз в точке входа `src/main.jsx`, компоненты - по месту применения:

```jsx
// src/main.jsx
import 'bootstrap/dist/css/bootstrap.min.css';
import './styles/theme.css';

// src/App.jsx
import Container from 'react-bootstrap/Container';
import Row from 'react-bootstrap/Row';
import Col from 'react-bootstrap/Col';
```

Импорт по отдельным путям, а не из корня пакета, оставляет в сборке
только использованные компоненты.

JavaScript-бандл Bootstrap не подключается: React Bootstrap реализует
поведение аккордеона, кнопок и полей средствами React, поэтому зависимость
от jQuery и от `bootstrap.bundle.js` отсутствует.

## Использованные компоненты библиотеки

| Компонент | Где применён | Что даёт |
|---|---|---|
| `Container`, `Row`, `Col` | `App` | Адаптивная сетка всех секций |
| `Card` с `Card.Img`, `Card.Body`, `Card.Footer` | `SpeakerCard` | Карточка спикера |
| `Button` | Первый экран, карточка, форма | Кнопки трёх вариантов оформления |
| `Badge` | `Favorites` | Метка счётчика избранного |
| `Stack` | Первый экран, `Favorites` | Раскладка с равными промежутками |
| `Accordion` | Секция FAQ | Раскрывающиеся вопросы |
| `Form` с `Form.Group`, `Form.Control`, `Form.Text` | `RegistrationForm` | Поле ввода и состояние ошибки |
| `Alert` | `RegistrationForm` | Сообщение об успешной отправке |

## Адаптивная сетка спикеров

Список спикеров выводится в `Row` с классом `g-4`, каждая карточка
занимает колонку:

```jsx
<Col xs={12} md={6} xl={3}>
```

| Диапазон ширины | Точка Bootstrap | Колонок в строке |
|---|---|---|
| до 767 px | `xs` | 1 |
| 768 - 1199 px | `md` | 2 |
| от 1200 px | `xl` | 4 |

В данных восемь докладов, поэтому на широком экране получаются две
строки по четыре карточки. Класс `h-100` на `Card` выравнивает карточки
одной строки по высоте независимо от длины темы доклада.

## Тема оформления

Собственных CSS-модулей в проекте не осталось: четыре файла
`*.module.css` из ЛР № 19 заменены одним файлом `src/styles/theme.css`.
Он не отменяет правила библиотеки через `!important`, а переопределяет
её CSS-переменные:

```css
:root {
  --bs-primary: #4f46e5;
  --bs-border-radius: 0.75rem;
}

.btn-primary {
  --bs-btn-bg: var(--brand-primary);
  --bs-btn-hover-bg: var(--brand-primary-hover);
}
```

Переменные берут значения из палитры дизайн-системы ЛР № 17, поэтому
фирменные цвета и радиусы наследуются всеми компонентами Bootstrap
без правки их разметки.

## Структура проекта

```
src/
├── App.jsx                     секции лендинга на Container/Row/Col
├── main.jsx                    точка входа, импорт стилей, Provider
├── assets/                     иконки и изображения из ЛР № 17
├── components/
│   ├── Favorites/              панель избранного: Badge, Button, Stack
│   ├── Icon/                   собственная иконка-маска из ЛР № 19
│   ├── RegistrationForm/       форма на Form и Alert
│   └── SpeakerCard/            карточка на Card
├── data/content.js             данные спикеров и вопросов
├── store/                      срез favorites и configureStore
└── styles/theme.css            тема поверх Bootstrap
```

Собственным остался только компонент `Icon`: в Bootstrap нет готового
решения для SVG-маски, залитой `currentColor`, а иконки проекта
подготовлены в ЛР № 17 именно в таком виде.

## Что можно проверить в интерфейсе

1. При изменении ширины окна список спикеров перестраивается в четыре,
   две и одну колонку.
2. Клик по звёздочке на карточке меняет вариант кнопки и увеличивает
   счётчик в метке «В избранном».
3. Кнопка «Очистить» снимает отметки сразу со всех карточек.
4. Отправка формы с некорректным адресом подсвечивает поле красным
   и показывает сообщение из `Form.Control.Feedback`, корректный адрес
   заменяет форму на `Alert`.
5. В секции FAQ открыт первый вопрос, открытие другого закрывает
   предыдущий.
